## Expectativa realista com R$ 1/dia

Seja transparente consigo mesmo: com R$ 30/mês, o Google Ads não vai te trazer
dezenas de clientes. O que ele vai fazer é **te dar presença** no topo da busca
para termos muito específicos, de pessoas prontas para contratar.

| Métrica                           | Estimativa realista (PT-BR, nicho jurídico/PI) |
| --------------------------------- | ---------------------------------------------- |
| CPC médio (palavras focadas)      | R$ 0,80 – R$ 2,50                              |
| Cliques/mês esperados             | **15 – 40 cliques**                            |
| Taxa de conversão de site jurídico| 2% – 8%                                        |
| Leads/mês esperados               | **0 – 3 por mês**                              |

> Com esse orçamento, pense no Ads como **uma vitrine barata no Google**, não
> como uma máquina de leads. Se um cliente fechado vale R$ 2.000+, mesmo
> **1 lead fechado a cada 2 meses já paga o ano todo de Ads com folga.**

### Quando aumentar o orçamento

- Se o CTR (taxa de cliques) passar de 5% — sinal de que os anúncios estão bem segmentados.
- Se o "Índice de qualidade" das palavras-chave ficar ≥ 7/10.
- Se começar a fechar 1+ cliente/mês — a partir daí, dobrar orçamento tem ROI direto.

## Estratégia para R$ 1/dia

Regras de ouro para não queimar o orçamento:

1. ✂️ **Só Rede de Pesquisa (Search).** Nada de Display, YouTube, Performance Max ou
   Discovery — comem o orçamento em minutos sem retorno para esse nicho.
2. 🎯 **Só palavras-chave em correspondência de frase e exata.** Correspondência ampla
   com R$ 1/dia é jogar dinheiro fora.
3. 🕐 **Programação de horários restrita** (seg–sex, 08h–20h). Anúncios rodando às 3h
   da manhã atraem clique curioso que não converte.
4. 📍 **Brasil inteiro, mas com lance +20% para Ribeirão Preto–SP e região.**
   Cliente local fecha mais fácil.
5. 📱 **Só desktop + mobile (sem tablet)** e **priorize mobile** — é onde a maioria
   busca "registrar marca urgente".
6. 🛑 **Lista robusta de palavras-chave negativas** (abaixo) para filtrar curiosos,
   estudantes, concursos, etc.
7. 📞 **Extensões de anúncio ao máximo** — elas são grátis, aumentam CTR e ocupam
   mais espaço na tela.

## Passo a passo — subir a campanha

### 1. Criar a conta

1. Vá em <https://ads.google.com/> → **Começar agora**.
2. **No rodapé**, clique em **"Alternar para o modo Especialista"** (muito importante —
   senão o Ads te obriga a criar uma "Campanha Inteligente" que queima orçamento).
3. Adicione o cartão em **Cobrança → Resumo**.

### 2. Criar ação de conversão

Siga o arquivo [`docs/GOOGLE_ANALYTICS_SETUP.md`](./GOOGLE_ANALYTICS_SETUP.md) (item 2).

### 3. Criar a campanha

1. **+ Nova campanha** → Objetivo: **Leads** → Tipo: **Rede de Pesquisa** →
   Como deseja atingir sua meta: **"Visitas ao site"** → URL: `https://arcanumpi.com.br`.
2. **Nome da campanha:** `Arcanum PI — Search Brasil`
3. **Redes:** desmarque "Rede de Display" e "Parceiros de pesquisa".
4. **Locais:** Brasil. Clique em "Opções de local" → **"Presença: pessoas que estão
   nos meus locais alvo"** (evita mostrar anúncio pra gente fora do Brasil pesquisando
   "brasil registro marca").
5. **Idioma:** Português.
6. **Orçamento:** R$ 1,00.
7. **Lances:** Maximizar cliques → **"Definir um lance máximo de CPC"** → R$ 1,50.
8. **Extensões:** adicione sitelinks, callouts, snippets, chamada (ver acima).

### 4. Criar os 3 grupos de anúncios

Para cada um dos 3 grupos (Marca, Patente, Software):

1. Nome do grupo: `Marca` / `Patente` / `Software`.
2. Lance padrão: R$ 1,00.
3. Cole as palavras-chave do grupo correspondente (já formatadas com `[]` e `""`).
4. Cole os títulos e descrições do anúncio correspondente (RSA).
5. URL final: a âncora do grupo (`#marcas`, `#patentes`, `#software`).

### 5. Configurações finais (depois de criar)

1. **Programação:** Configurações → Programação de anúncios → Seg–Sex 08h–20h.
2. **Dispositivos:** Configurações → Dispositivos → Tablet = **−100%**.
3. **Ajuste por local:** Configurações → Locais → adicione Ribeirão Preto–SP
   com **+20%**.
4. **Palavras-chave negativas:** cole a lista inteira em
   Ferramentas → Bibliotecas compartilhadas → Listas de negativas → aplique à campanha.
5. **Conversões:** Configurações → Conversões → incluir `Lead — Formulário de contato`.

### 6. Aguarde 24h e revise

- Veja "Termos de pesquisa" (o que as pessoas **realmente** digitaram). Adicione
  qualquer termo irrelevante como negativa.
- Veja "Recomendações" (aba no topo). **Ignore** sugestões para "aumentar
  orçamento", "ampliar palavras-chave", "ativar Display" — são o Google
  querendo mais dinheiro.

## FAQ rápido

**Q: R$ 1/dia realmente funciona?**
A: Funciona para presença e captura de leads ocasionais. Não funciona para
"escala". Pense nele como R$ 30/mês de "custo de existir no Google".

**Q: Quanto demora pra ver resultado?**
A: Primeiros cliques em 24–48h. Primeiras métricas confiáveis em ~30 dias
(quando tem volume de dados pro Google otimizar).

**Q: O Google vai me ligar oferecendo "ajuda"?**
A: Vai sim. São vendedores, não otimizadores. **Recuse educadamente.** As
sugestões deles quase sempre são para aumentar orçamento / ativar Display.

**Q: Posso pausar a qualquer momento?**
A: Sim, sem multa. Clique em "Pausar" na campanha e cobrança para.

**Q: Pós-pagamento ou pré-pago?**
A: Automaticamente pós-pagamento no cartão (cobrança mensal ou a cada R$ 120
gastos, o que vier primeiro). Tem opção de pré-pagamento (boleto) se preferir.
